Variable Font Axes

One font file can hold a range of styles. An axis is a setting you can adjust, like the thickness of the letters.

One file, three weights

All three samples use Recursive. The number controls the thickness of the letters.

In @font-face, the range tells the browser which weights the file can provide.

@font-face {
  font-family: "Recursive";
  src: url("recursive.woff2") format("woff2-variations");
  font-weight: 300 1000;
  font-display: swap;
}

Try two custom axes

MONO gives every letter the same width. CASL makes the letter shapes more casual.

Make space for good type.

font-variation-settings: "MONO" 1, "CASL" 0;

Click Monospace, then Casual only. The new declaration replaces the whole list, so MONO returns to its default. Click Both to keep both settings.

Animate a weight change

Hover over the text or focus it with Tab. The browser redraws the letter shapes during the transition, so this one lasts 250 ms. With reduced motion enabled, the weight changes instantly.

Light to bold

.animated {
  font-weight: 400;
  transition: font-weight 250ms ease;
}
.animated:is(:hover, :focus-visible) {
  font-weight: 800;
}
@media (prefers-reduced-motion: reduce) {
  .animated { transition: none; }
}

Which CSS property should I use?

Use the dedicated CSS property for a registered axis when your font supports it. Use font-variation-settings for custom axes.

  • Weight (wght) uses font-weight.
  • Width (wdth) uses font-stretch.
  • Slant (slnt) uses font-style: oblique with an angle.
  • Italic (ital) uses font-style: italic.
  • Optical size (opsz) uses font-optical-sizing.

Compare actual file sizes when choosing a font. One variable file can save downloads when you need several weights.
