How my colors work

My starting colors are defined in css/tokens/colors.css. I use a teal accent with lighter and darker versions made from the same color.

Shared tokens control the backgrounds, text, links, and borders. Each token has a light and dark value, so both pages change together.

Try the theme

Use the theme button at the top to choose a mode. Then visit the homepage or refresh this page to check that your choice stays saved.

System default follows your computer’s color setting.
