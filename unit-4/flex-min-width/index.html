When CSS layouts won’t shrink

01 · A photo gallery in a flex row

The long filename gives the content area an automatic minimum width. Inspect .content in DevTools and look for min-width: auto in the Computed panel.

Before

Albums
tetons-sunset-original-full-resolution-panorama-november.jpg 
.gallery { display: flex; }
.content { flex: 1; }

Try the fix

Albums
tetons-sunset-original-full-resolution-panorama-november.jpg 
.content { flex: 1; min-width: 0; }
.filename {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

min-width: 0 lets the flex item get narrower. The rules on .filename show the ellipsis once the space gets tight.

02 · A photo panel in a flex column

The panel has a fixed height. Toggle the fix and watch where the photos scroll.

Weekend gallery
.panel {
  display: flex;
  flex-direction: column;
  height: 10rem;
}
.panel-body { flex: 1; min-height: 0; }
.photos { height: 100%; overflow-y: auto; }

The flex item is .panel-body. Its child, .photos, handles scrolling.

03 · The same gallery in Grid

A 1fr track has an automatic minimum. Here the long filename can stretch the second column. The minimum depends on how the grid tracks are defined and which ones the item spans.

Albums
tetons-sunset-original-full-resolution-panorama-november.jpg 
.grid-gallery {
  display: grid;
  grid-template-columns: 5rem 1fr;
}
.content { min-width: 0; }

04 · Padding on a full-width photo card

With content-box, the card takes up 100% of the parent’s width, then adds padding and borders. With border-box, those fit inside the declared width.

Sunset photo card 
.padded-card {
  width: 100%;
  padding: 1.1rem;
  border: 3px solid;
  box-sizing: border-box;
}

Use the reset below for consistent box sizing across a project. Apply min-width: 0 to individual items that need to shrink past their automatic minimum.

*, *::before, *::after {
  box-sizing: border-box;
}
