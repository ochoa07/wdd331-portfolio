Aspect Ratio & Object Fit

Choose the shape. Fit the image. Control the crop.

Every example uses the same landscape illustration. Watch the round sun: stretching makes it oval.

1. Fix a stretched image, one step at a time

This image is inside a grid. We deliberately set a mismatched width and height to stretch it. Grid alone does not automatically distort images.

A project card

First change the box’s shape. Then fix how the picture fits.

The fixed height and fill value stretch the picture.


        
16 / 9 means 16 units wide for every 9 units tall. At least one dimension must be automatic for aspect-ratio to calculate it. Unlike a fixed height, the ratio adapts as the width changes.

        
Older layouts often used padding-top: 56.25% and an absolutely positioned child to create a 16:9 box. Today, aspect-ratio expresses the shape directly.

    

    

        
2. Compare cover, contain, and fill

        
Same image. Same box. Different ways to fit the picture. The checkerboard makes empty space visible.

        


cover
Keeps proportions, fills the box, and crops the sides.
aspect-ratio: 1;
object-fit: cover;
contain
Keeps proportions and shows the whole image, with empty space.
aspect-ratio: 1;
object-fit: contain;
fill
Fills the box by stretching the image. Look at the sun!
aspect-ratio: 1;
object-fit: fill;

        

        

        

        

        

        
none keeps the image at its natural size (800 × 500 here); the image box clips anything outside it. scale-down chooses the smaller result of none and contain, so it never enlarges the image.

    

    

        
3. Choose which part stays visible

        

            

            
Cover crops this wide image inside a square. Move the picture to keep the tree on the left or the cabin on the right.

                
                

                
Position only creates a visible change along an axis with extra image content or empty space. For a tall portrait cropped into a square, try center top to keep the face visible.

            

        

    

    

        
4. Keep a hero box proportional

        
Move the slider or resize the browser. The container calculates its height from its width.

        
        
        

        
.hero {
    aspect-ratio: 16 / 9;
}

.hero img {
    width: 100%;
    height: 100%;
    object-fit: cover;
}

        
The same ratio container can hold a video or iframe. Give the child width: 100% and height: 100%. Object-fit works on images and videos; it does not control the content inside an iframe.

.card img {
    display: block;
    width: 100%;
    height: auto;
    aspect-ratio: 16 / 9;
    object-fit: cover;
    object-position: center;
}

        
For the assignment, apply this pattern to at least one actual image or video on your portfolio inside Grid or Flexbox. These sample cards demonstrate the pattern; they do not replace that portfolio update.

    

    
6. What to remember

        
aspect-ratio: the shape of the box.

        
object-fit: how the picture fits inside the box.

        
object-position: where the picture sits inside the box.

        
Use cover for thumbnails, contain when the whole picture matters, and fill only when stretching is intended.
