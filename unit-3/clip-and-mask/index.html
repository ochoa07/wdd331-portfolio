Clip Path & Mask Image

Cut a shape. Create a fade. See the difference.

1. Clip an element into a shape

Clipping hides everything outside the shape. The checkerboard shows the area behind the element. Its original layout space stays the same.

Circle

clip-path: circle(45% at 50% 50%);

Triangle

clip-path: polygon(
    50% 0%,
    100% 100%,
    0% 100%
);

Inset

clip-path: inset(12% 8% round 24px);

Polygon points use x then y: 0% 0% is the top-left corner; 100% 100% is the bottom-right. Inset values here mean 12% from top/bottom and 8% from left/right.

2. Animate between matching shapes

Hover over the image, or use the buttons. A square and diamond both use four points, so their points can move smoothly.

Move the pointer away from the image before using the buttons. Watch the triangle jump because it has three points. 

.morph {
    clip-path: polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%);
    transition: clip-path 1s ease;
}

.morph-frame:hover .morph {
    clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
}

For this basic shape transition, use the same shape function and matching polygon point counts. Reduced-motion settings disable this animation.

3. Reveal an element with a gradient mask

Original

Gradient mask

.fade {
    mask-image: linear-gradient(to bottom, black 35%, transparent 100%);
    mask-mode: alpha;
    mask-size: 100% 100%;
    mask-repeat: no-repeat;
}

With an alpha mask, black does NOT paint the image black. Opaque black reveals it, transparent hides it, and partial opacity creates the fade. Opaque white would also reveal it. Luminance masks additionally use brightness.

Older WebKit browsers needed -webkit-mask-image. Current major browsers support the standard property. In DevTools, uncheck the prefixed declaration: current browsers should keep the fade because the standard declaration remains. The source includes prefixed versions for older browsers.

4. The repeating mask gotcha

A 70px mask repeats across the image. Masks repeat by default; this is easiest to notice when the mask is smaller than the element. 

mask-size: 70px 70px;
mask-repeat: repeat;

no-repeat stops the tiling. Changing the size to 100% 100% also stretches the mask to cover the element.

5. What to remember

Use clip-path for a defined shape, and mask-image for fades or detailed transparency.

Good uses: shaped decorative images, geometric reveals, and image fades. Keep important text and controls outside areas you hide. Neither property makes text wrap around a shape; that is a separate job for shape-outside.
